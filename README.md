# Concept Spaces

**Intelligence, Given Form.**

Foundation monorepo for the Concept Spaces autonomous, human-governed AEC operating system.

## Current Build Pack

Build Pack 30 activates governed **Building Git & Change Impact** on top of Project Truth, deterministic parcel geometry, REGULA, Building Compiler™, Design Genome™, Engineering Verification & Validation, Cross-Discipline Coordination and Release Assurance.

The current operating stack includes:
- authenticated project onboarding and Project Truth
- deterministic site geometry evaluation
- executable REGULA applicability and compliance evaluation
- Building Compiler™ input freezing, governed stage ledger and human Pareto shortlisting
- Design Genome™ project-outcome capture, privacy review and sequential human-governed learning promotion
- versioned engineering engine certification, benchmark evidence and criticality coverage
- immutable engineering calculation provenance and exact-hash professional review
- atomic cross-discipline coordination issue + matrix creation
- source/target CDE and project-resource hash capture with freshness enforcement
- governed coordination re-baselining and exact-hash deviations
- deterministic project configuration hashing across Truth, requirements, CDE, models, coordination, REGULA, cost and releases
- Building Git `main` bootstrap, exact-head option branches and immutable commit lineage
- governed branch freeze/reactivate/abandon controls and two-parent merges
- project change proposals with declared source objects and affected disciplines
- Change Impact Engine™ blast-radius analysis across requirements, rules, documents, models, engineering, coordination, BOQ, contracts, programme and releases
- immutable impact analysis hashes, Decision Reversal Cost™, criticality and confidence
- exact-hash maker-checker change approval with C3/C4 professional eligibility inherited from the approval runtime
- fail-closed re-analysis when the project configuration changes after analysis
- approved change commits and governed branch merge
- package-specific release gates with exact package-content-hash safety cases
- source-bound release evidence, professional review, fresh pre-approval/pre-issue evaluation and zero-critical-escape enforcement
- immutable audit events across configuration, coordination and release decisions

The platform does **not** treat a prior analysis, coordination resolution or approval as permanently valid. Changes in the governed project configuration invalidate stale downstream evidence and require explicit re-analysis or re-baselining before progression.
