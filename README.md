# Concept Spaces

**Intelligence, Given Form.**

Foundation monorepo for the Concept Spaces autonomous, human-governed AEC operating system.

## Current Build Pack

Build Pack 27 activates the governed **Engineering Verification & Validation runtime** on top of the live Project Truth, deterministic parcel geometry, REGULA compliance, Building Compiler™ and Design Genome™ runtimes.

The current operating stack includes:
- authenticated project onboarding and Project Truth
- deterministic site geometry evaluation
- executable REGULA applicability and compliance evaluation
- Building Compiler™ input freezing, governed stage ledger and human Pareto shortlisting
- Design Genome™ project-outcome capture, privacy review and sequential human-governed learning promotion
- versioned engineering engine registry with checksum/build identity
- benchmark suites, version-bound benchmark results and criticality coverage
- fail-closed engine certification and enablement
- project MEPF/ELV/VT system criteria registration
- immutable engineering calculation provenance with input/output hashes, standards, units and execution evidence
- verified-credential professional review bound to the exact calculation output hash
- explicit `NOT_VERIFIED`, `AUTOMATED_VALIDATED`, `PROFESSIONALLY_REVIEWED` and release-eligibility states
- independent professional review requirement for C3/C4 calculation authors

The platform does **not** invent engineering calculations. A calculation record is accepted only as provenance from an eligible certified engine version, and it remains blocked from release eligibility until the applicable professional review is valid for the exact output hash. Final package release remains governed by the separate Release Assurance gate.
