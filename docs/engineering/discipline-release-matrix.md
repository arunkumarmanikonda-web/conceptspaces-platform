# Discipline Release Matrix

| Discipline | Automated Drafting | Deterministic / Physics Validation | Professional Review | C3/C4 Self-Issue Allowed |
|---|---|---|---|---|
| Architecture | Yes | Rules / geometry / coordination where applicable | Required by project authority matrix | No |
| Interiors | Yes | Material / fire / accessibility / coordination checks where applicable | Required where project/stage demands | No |
| Structure | Advisory / drafting only | Required | Required | No |
| Mechanical | Advisory / drafting only | Required for load/sizing outputs | Required | No |
| Electrical | Advisory / drafting only | Required for load/sizing/protection outputs | Required | No |
| Plumbing | Advisory / drafting only | Required for demand/sizing outputs | Required | No |
| Fire / Life Safety | Advisory / drafting only | Required | Required | No |
| ELV / BMS | Yes within configured scope | Required where calculations/rules apply | Required by stage/criticality | No |
| Vertical Transport | Advisory / option analysis | Required for traffic/design criteria where applicable | Required | No |
| Sustainability | Yes | Simulation evidence required for quantitative claims | Required by stage/claim | No |

The release matrix is a governance minimum. Jurisdictional rules, project authority, contract requirements and specialist obligations may impose stricter controls.
