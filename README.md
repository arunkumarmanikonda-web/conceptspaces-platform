# Concept Spaces

**Intelligence, Given Form.**

Foundation monorepo for the Concept Spaces autonomous, human-governed AEC operating system.

## Current Build Pack

Build Pack 01 establishes:
- Next.js public and application shells
- Super Admin shell
- Project onboarding foundation
- PostgreSQL/Supabase schema + RLS
- RBAC/ABAC policy model
- immutable audit + outbox foundations
- workflow/job-control data model
- CDE/storage foundations
- CI/CD, IaC stubs, observability and runbooks

No production engineering calculation or IFC release is permitted until its discipline validation gate is implemented.
