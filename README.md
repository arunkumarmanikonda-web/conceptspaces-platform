# Concept Spaces

**Intelligence, Given Form.**

Foundation monorepo for the Concept Spaces autonomous, human-governed AEC operating system.

## Current Build Pack

Build Pack 28 activates the governed **Release Assurance runtime** on top of the live Project Truth, deterministic parcel geometry, REGULA compliance, Building Compiler™, Design Genome™ and Engineering Verification & Validation runtimes.

The current operating stack includes:
- authenticated project onboarding and Project Truth
- deterministic site geometry evaluation
- executable REGULA applicability and compliance evaluation
- Building Compiler™ input freezing, governed stage ledger and human Pareto shortlisting
- Design Genome™ project-outcome capture, privacy review and sequential human-governed learning promotion
- versioned engineering engine certification, benchmark evidence and criticality coverage
- immutable engineering calculation provenance and exact-hash professional review
- package-specific release gates with explicit evidence policy and criticality
- exact package-content-hash safety cases; changed content requires a new case
- source-bound capture of current Project Truth, REGULA, engineering, coordination and client evidence
- package-level professional review bound to the exact content hash and verified credential
- fresh evidence re-evaluation before approval and again immediately before issue
- governed release exceptions with C3/C4 zero-critical-escape enforcement
- fail-closed `blocked`, `ready_for_review`, `approved` and `issued` release states
- immutable audit events for gate, safety-case, evidence, exception, approval and issue decisions

The platform does **not** equate an engineering calculation, a professional review, or an administrative approval with package release. Final issue requires the complete current evidence set for the exact package hash, zero unresolved C3/C4 escape, and a fresh final evaluation. Administrative privilege cannot bypass those invariants.
